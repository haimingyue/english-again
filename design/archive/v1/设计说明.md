# 英语自学指北官网 UI 第一版

这套图把已确认的七个独立页面整理为同一套桌面端视觉设计，供逐页讨论布局、内容重点与视觉风格。图片由内置 ImageGen 生成，实际尺寸均为 1190 × 1322 像素。它们是静态 UI 概念图，交互与页面文案仍需在后续实现中确认。

## 视觉方向

暖白背景、橙红强调色、深棕正文与少量鼠尾草绿，延续已有软件的阅读氛围。大标题采用宋体风格，导航和正文采用清晰的无衬线字体。七页共用导航与页脚，栏目顺序为首页、介绍、音标、语法、资源、专栏、工具。

首页及知识页使用纸卡、书本与学习笔记插画；资源和专栏用列表承载查找任务；工具页展示用户提供的自研软件界面。

## 后续内容核对

- 介绍页的说明是布局用的拟定文案。用户提供参考资料后，再选材并明确学习原则，不将生成图中的概括当作已核验的研究结论。
- 音标是图像文字，正式实现时需使用准确的 IPA 字符；首页插画与美式音标内容页的转写记法也应统一。
- 专栏使用真实周次和主题。列表摘要、缩略图为设计示意，视频与 BV 链接的对应关系仍需逐一核实。
- 资源页的卡牌与资料入口是拟定布局；具体卡组文件、资料内容和使用说明还需补齐。
- 工具页依据用户软件截图生成展示图，图内软件文字与细节可能有重绘差异。实际开发时嵌入原始截图，并确定获取方式。
- 本版绘制桌面页面，移动端布局尚未设计。
